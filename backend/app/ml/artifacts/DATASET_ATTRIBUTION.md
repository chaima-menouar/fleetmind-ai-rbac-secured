# Dataset attribution

The bundled model, metadata, and twelve small evaluation examples were derived
from **APS Failure at Scania Trucks**, donated by Everingham and publicly listed
by the UCI Machine Learning Repository.

- Dataset page: <https://archive.ics.uci.edu/dataset/421/aps%2Bfailure%2Bat%2Bscania%2Btrucks>
- DOI: <https://doi.org/10.24432/C51S51>
- UCI catalog license: CC BY 4.0
- Accessed: 2026-09-03

No complete copy of the raw dataset archive is distributed with FleetMind AI.
The full dataset remains available from UCI under its stated terms.
